The story

Every factory machine follows a list of rules.

A small computer called a machine controller runs those rules, every few milliseconds, all day.

IF Start is pressed → run the conveyorIF Stop is pressed → stop the conveyor
Late 1960s

Factories start using these controllers instead of walls of wiring.

Decades since

Plants are built around them. Many still run on models from the 1980s and 90s.

Today

The maker is phasing out older models. Factories have to move every rule to a new controller.

Rockwell Automation, the controller maker: "Some SLC 500 Bulletin numbers are discontinued… Customers are encouraged to migrate." Source

Today's tools

There are tools to rewrite the rules. None checks the result behaves the same.

Translators

Rewrite the old rules for the new controller, automatically or with AI.

Text compare

Show which lines of the rules changed. Not what the machine will do.

Simulators

Run one controller on a computer. A person still presses buttons and compares by eye.

The gap

So people check the new rules by hand. Mistakes slip through.

By hand

Even the translator's maker tells engineers to "locate, analyze, and fix any discrepancies" themselves.

~9 in 10

In a 2026 study, AI translated about 9 in 10 parts of a program correctly. Nobody tested how the result behaves.

$187K

The cost of one hour of a stopped production line in heavy industry. A missed rule is found on the factory floor.

Sources: Rockwell, conversion tool · Ogundare et al. 2026, 90.6% (396 of 437 parts), one program · Senseye 2021, $187,500/hour

Our solution

LadderProof is a test drive for the new controller.

It runs the old rules and the new rules side by side on a computer, presses the same buttons in both, and flags the first moment they act differently.
